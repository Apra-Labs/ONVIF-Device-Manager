FFmpeg n7.1 Win32 Build
=======================
BtbN no longer provides 32-bit Windows builds for FFmpeg 7.x.
For Win32 builds, see:
- https://www.gyan.dev/ffmpeg/builds/ (check if win32 is available)
- Compile FFmpeg from source with MinGW-w64 32-bit toolchain

Note: The project's Win32 configuration is legacy. x64 is recommended.
